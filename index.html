Route a task to the exact organs it needs.

Seven capability stages — Prove · Own · Shape · Carry · Remember · Run · Connect. A task needs some non-empty combination of them; there are exactly 127 such combinations, each a stable address. This router maps a need to the precise set of estate organs that serve it — and a coverage gate proves no task falls through a silent gap. Kernel-backed by the witness-gated router.mjs.
